# Instructions for Schedules Directory

When working with school schedules in this directory:

1. **Execute Autonomously**: Run the entire update/conversion process from start to finish without pausing for step-by-step approvals.
2. **Self-Contained Adaptation**: Each school directory may have its own conversion script (`convert_excel_to_docx.py`, `convert_schedule_to_lists.py`) and mappings. Autonomously inspect input files, update mappings, fix issues, and run the scripts.
3. **Report at the End**: Report results only after the process is completed.
